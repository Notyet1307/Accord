从自然对话到受管 Workflow Run

本原型只回答一个问题：用户只在群聊或 Bot 私聊提出任务时，平台能否自动路由、补充缺失信息、恢复同一个 Run，并让 Human 与专业 Agent 在清晰责任边界下完成工作。

完全合成、不可交付：页面不联网、不保存数据、不调用模型。Wake Router 与 Work Router 是平台服务，不是假装成 Agent 的大模型；茉莉是用户可见的默认负责人。
